## Lolos (sudah benar)

- **Konsistensi token 100%**: seluruh 8 file memakai hex token yang persis sama dengan DESIGN.md (`--bg #161311`, `--surface #201c18`, `--orange #ff8f52`, pasangan status SUK/PRC/GGL, dsb.); tidak ada hex di luar token (pindai seluruh file — temuan `#883xx` hanya nomor tiket deposit di teks).
- **Kontras teks kecil dihitung, semua ≥ 4.5:1**: `--muted` di `--bg` = 8.06:1; `--body` di `--surface` = 11.17:1; `--info` di atas tint chip (`.b-inf` monitor-bulk) = 4.98:1; `--info` di `.bdg` mutasi-dompet = 5.13:1; `--err-ink` di `--err-bg` = 7.40:1; `--warn-ink` di `--warn-bg` = 9.20:1.
- **Aksesibilitas dasar**: `:focus-visible` outline oranye 2px di semua file; `prefers-reduced-motion` menonaktifkan animasi/flash/denyut; tombol ikon rail + bottom-nav semua ber-`aria-label`; input berlabel (`<label for>` / aria-label); bottom-nav item `min-height:48px`; tabel ber-`aria-label`; bar sinyal/log mengikuti pola.
- **Fungsionalitas mockup (diuji via klik nyata)**: wizard 3 langkah (primer disabled sampai valid → pilih tipe → parameter → tinjau → simpan; Esc/dirty → konfirmasi tutup); monitor-bulk (chip filter, pencarian, jeda-live, bulkbar "N dipilih" + aksi); mutasi-dompet (chip filter dompet 24→8 baris); daftar-hitam (tambah nomor + normalisasi, dialog konfirmasi destruktif "Nonaktifkan reseller?" dengan fokus default Batal); pengguna-peran (tambah pengguna + validasi, toggle matriks peran); form-transaksi-manual (error inline per-field + tombol disabled sampai valid).
- **Anti-slop & brief**: dark-first `#161311`, Bahasa Indonesia sentence case ("Jeda live", "Tambah nomor", "Buat transaksi"), tidak ada eyebrow ALL-CAPS di copy (badge dikecualikan — lihat F2), tidak ada fade-slide-up massal/parallax/glassmorphism; densitas tabel 31px/baris dipertahankan; motion hanya sinyal (flash baris, denyut PRC/live).
- **Mobile (5 file bersih)**: wizard-modul, monitor-bulk, form-produk, form-transaksi-manual, administrasi-jawaban — tidak ada overflow halaman (scrollWidth = 390), tabel scroll-x di `.tbl-wrap` sesuai §3, bottom-nav tampil ≤900px.
